# Blockers

Use this file to record issues that prevent the agent from continuing. A new session should read this file to understand what human intervention is needed.

## Instructions for Agents

- Write one entry per blocker.
- Include enough detail for a human or another agent to act on it.
- After writing a blocker, move on to a non-blocked task.
- Remove entries when they are resolved.

## Template

```markdown
## [YEAR-MM-DD] Blocker title

**Severity:** High | Medium | Low
**Task:** The task that is blocked
**Detail:** What is missing or broken
**Workaround:** None | [description]
```
