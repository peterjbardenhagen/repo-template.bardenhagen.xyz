# Progress Tracker

Use this file to track progress during an autonomous agent session. A new agent session should read this file first to resume work.

## Instructions for Agents

- Read this file at the start of the session.
- Update the `Last Updated` timestamp after each phase.
- Mark completed items with `[x]`.
- Write a `DONE` marker on its own line when the overall task is complete.
- If you encounter a blocker, record it in `blockers.md` and move to the next non-blocked task.

## Template

```markdown
# Progress Tracker

**Last Updated:** YYYY-MM-DD HH:MM UTC
**Current Phase:** Phase N — [name]
**Status:** In Progress

## Completed
- [x] Task one
- [x] Task two

## In Progress
- [ ] Task three

## Upcoming
- [ ] Task four
- [ ] Task five
```
