# SEO Implementation Checklist

## On-Page SEO

### Title Tags & Meta Descriptions
- [ ] Title tags: 50-60 characters
- [ ] Meta descriptions: 150-160 characters
- [ ] Unique for each page
- [ ] Include target keyword
- [ ] Compelling copy (CTR focused)

### Headings & Content
- [ ] One H1 per page
- [ ] Proper hierarchy (H1 → H2 → H3)
- [ ] Keyword in H1 and at least one H2
- [ ] Content length: 1000+ words (for main pages)
- [ ] Keyword density: 1-2% natural inclusion
- [ ] Bold/italics for important terms

### Images & Media
- [ ] All images have alt text
- [ ] Alt text includes target keywords (naturally)
- [ ] Images properly sized and optimized
- [ ] WebP format with fallbacks
- [ ] Video with proper meta tags

### Internal Linking
- [ ] Internal links on every page
- [ ] Anchor text is descriptive (not "click here")
- [ ] Proper heading structure followed
- [ ] Link density: 3-5 links per 1000 words
- [ ] Breadcrumb navigation implemented

### Technical SEO

#### Sitemap & Robots
- [ ] Sitemap.xml generated and submitted
- [ ] robots.txt configured properly
- [ ] robots.txt allows Googlebot
- [ ] Correct XML structure

#### URL Structure
- [ ] Lowercase URLs
- [ ] Hyphens for word separation (no underscores)
- [ ] Readable, descriptive URLs
- [ ] No parameters in main URLs
- [ ] Permanent redirects (301) for URL changes

#### Mobile & Performance
- [ ] Mobile-responsive design
- [ ] Viewport meta tag correct
- [ ] Page speed > 90 Lighthouse score
- [ ] Core Web Vitals all green

#### Structured Data
- [ ] Schema.org markup implemented
- [ ] JSON-LD format used
- [ ] Organization schema
- [ ] Product/Service schema
- [ ] Breadcrumb schema
- [ ] FAQ schema (if applicable)
- [ ] Tested with Schema.org validator

### Social Media Tags
- [ ] Open Graph tags present
- [ ] Twitter Card tags
- [ ] Social images 1200x630px
- [ ] Compelling social copy

### Canonical Tags
- [ ] Canonical URLs specified
- [ ] No canonical to external sites (usually)
- [ ] Canonical for pagination
- [ ] Consistent across variations

## Off-Page SEO

### Backlinks
- [ ] Strategy for quality backlinks
- [ ] High-authority sites targeted
- [ ] Relevant industry links
- [ ] No paid links (violates guidelines)
- [ ] Link velocity gradual, natural

### Local SEO (if applicable)
- [ ] Google My Business profile
- [ ] Name, address, phone consistent
- [ ] Local citations built
- [ ] Reviews encouraged
- [ ] Local keywords targeted

## Quick Wins (Implement First)

1. **Meta Tags** (1-2 hours)
   - Audit current meta tags
   - Optimize titles and descriptions
   - Ensure uniqueness

2. **Structured Data** (2-3 hours)
   - Implement Organization schema
   - Add Product/Service schema
   - Test and validate

3. **Images** (1 hour)
   - Add alt text to all images
   - Optimize file sizes
   - Use WebP format

4. **Internal Linking** (1-2 hours)
   - Audit current links
   - Add strategic internal links
   - Update anchor text

5. **URL Structure** (1-2 hours)
   - Audit URL structure
   - Create redirects if needed
   - Update sitemaps
