- Dependabot configuration
- Project tooling (`.editorconfig`, `.gitattributes`, `.gitignore`, `.env.example`, `.prettierrc`, `docker-compose.yml`, `Dockerfile`)
- Documentation (`docs/agentic-sdlc.md`, `docs/architecture.md`, `docs/decisions/`, `docs/getting-started.md`)

- Template seeds (`seeds/nextjs`, `seeds/dotnet`, `seeds/python`)
- Changelog & version tracking
