# Next.js Project Seed

Use this seed when creating a new Next.js project from the template.

## Files to Add After Init

```bash
npx create-next-app@latest . --typescript --tailwind --app --src-dir
```

## Template Notes

- `AI_CONTEXT.md` — Update stack to "Next.js / TypeScript / Node.js 20+"
- `docs/architecture.md` — Document your app router structure
- .env.example — Add your Next.js env vars (NEXT_PUBLIC_*, etc.)
